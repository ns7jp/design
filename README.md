# 設計書基礎演習案件パック

未経験からサーバー構築エンジニアを目指す人向けのポートフォリオです。架空企業「**株式会社サンプル物産**」(卸売業・従業員60名)の社内ITインフラ刷新案件を題材に、要件定義から運用保守までの設計書一式を、実務の体裁を保ちながら**初心者が読んでも理解でき、理由まで理解して自然に覚えられる**ように作成しています。

> 登場する企業・数値・IPアドレスはすべて演習用の架空設定です(WANの例示IPアドレスにはRFC5737のTEST-NET-3を使用しています)。

## この案件について

| 項目 | 内容 |
|---|---|
| 発注者 | 株式会社サンプル物産(架空企業・卸売業・従業員60名) |
| 課題 | 老朽化したファイルサーバ、アカウント管理の乱立、監視の不在、バックアップ運用の不備 |
| ゴール | ファイル共有基盤・認証基盤・社内ポータル基盤・監視基盤・バックアップ基盤の刷新を、セグメント分離された安全なネットワーク上に実現する |
| 構築対象 | サーバ9台(ゲートウェイ/FW、DNS/DHCP、LDAP認証、Web、DB、ファイル共有、監視、バックアップ、管理端末) |
| ネットワーク | 5セグメント(WAN/管理LAN/サーバLAN/内部LAN/DMZ)、VLANで分離 |
| OS / 主要ミドルウェア | AlmaLinux 9.4 / BIND・Kea DHCP / OpenLDAP / Apache・PHP / MariaDB / Samba / Zabbix / rsync |
| 学習環境 | VirtualBox 7.x 上に仮想マシンとして構築(自宅PC1台で再現可能) |
| 本番想定 | オンプレミス物理サーバ2台 + VMware ESXi によるサーバ仮想化 |

## このポートフォリオの読み方のポイント

- 各文書の冒頭に **📘 学習ポイント**(この文書が実務で何のために使われるか)を用意しています。
- 本文中の要所に **💡 なぜこう設計するのか**(設計の意図・理由)を挟み、暗記ではなく理解を優先しています。
- 専門用語は初出時に簡潔な説明を添え、[用語集](docs/12_用語集.md)を随所から参照できるようにしています。
- IPアドレスやサーバ一覧などの数値は、DOC-01〜DOC-13すべてで整合するように作成・検証しています。
